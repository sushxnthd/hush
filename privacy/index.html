Privacy notice · updated 7 October 2026

Your context belongs to you.

This notice covers the Hush website, sample walkthrough and current local alpha.

This website.

This version has no Hush account, signup form, analytics script or tracking cookie. Fonts, images, videos and scripts are served with the website. GitHub Pages hosts it and may process request metadata such as IP addresses according to GitHub’s privacy statement.

The browser walkthrough.

It uses sample preferences, sample memory and a simulated message. Your choices are held in this page’s memory. They are not saved to local storage or sent to a Hush service. Reloading or leaving the page resets the walkthrough.

Clipboard and external links.

Copy buttons write the displayed setup commands or prompt to your clipboard when you click them. Links to GitHub, Node.js, Git and other destinations leave this site; those destinations have their own policies.

The local engineering alpha.

The server binds to your computer’s loopback address. Local state is stored under the project’s data/ directory. Private-context encryption uses the passphrase you configure. Some operational records and audit state have different storage protections; the alpha does not promise that every local file is encrypted.

Model connections, upstream MCP services, connectors and sync workflows may communicate with destinations you configure. Local-first does not mean every configured workflow is offline.

Managing local data.

Use the local dashboard’s removal controls for supported records. To remove the entire local store, stop the server and remove the project’s data/ directory after preserving anything you need. This also removes local keys and can make dependent encrypted data unrecoverable. Any configured external service may retain its own records.

Questions.

Use Support for general questions and the security policy for security reporting options. Do not include private records in public issues.
