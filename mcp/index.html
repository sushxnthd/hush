A local boundary for your AI.
Connect through MCP.

Use Hush’s local runtime from a compatible MCP client. Private queries, bounded decisions and memory proposals stay behind a same-device boundary with explicit authority.

Connect

Start Hush with an available OS keystore. Authentication is enabled by default. For a client that supports local stdio MCP, generate its configuration from the same installation:

Paste the resulting JSON into your client’s MCP settings. It uses the local Hush bridge and derives its separate transport credential from the OS keystore; no bearer token goes in the configuration file.

Clients that support authenticated HTTP MCP can use http://127.0.0.1:8787/mcp with the documented local transport token. The stdio bridge supports Hush’s native JSON tools; use HTTP directly for an upstream streaming proxy.

The tools a client gets

These names come from the current runtime interface. Owner operations and MCP authority remain separate.

ToolPurpose
hush_begin_private_taskBegin a scoped private-task session.
hush_private_queryRequest permitted information through the private boundary.
hush_private_decisionCompute a bounded decision without returning the exact private inputs.
hush_route_taskRoute an authorized task to a supported path.
hush_propose_memoryPropose a memory for explicit owner review.
hush_revoke_private_taskEnd the task’s scoped authority.

Your boundary

An agent can propose. The owner decides what becomes memory and what authority is granted. A transport token is not owner authentication. Resolved proposals drop their duplicate plaintext value; approved memory remains in the encrypted Context Kernel.

Clients

Use a client that supports local stdio or authenticated HTTP MCP. Run npm run doctor to check authentication, keystore, audit integrity and private context before connecting. For any AI without MCP, the browser workspace prepares reviewed clipboard context you can paste manually.

This website cannot connect to your machine’s runtime. Native distribution remains a release candidate until signing, provider validation and independent assurance are complete.
