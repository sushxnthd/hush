The model is not the security boundary

Personal context moves toward the decision, not toward the model.

An agent sends public candidates and a bounded request. Supakeep evaluates that request against private state locally. The agent gets the answer it needs, not a copy of the profile that produced it.

01

Blind personalization.

Agents send candidates and a decision request instead of demanding your profile. Supakeep can locally rank flights, products, jobs, schedules, or actions using private user state.

02

Bound the information channel.

Private Decision Programs expose finite outputs whose maximum capacity is known before execution: a boolean is at most 1 bit; one of 16 outcomes is at most 4 bits. Repeated decisions share one trajectory budget.

03

Broker authority, not secrets.

Credentials and exact values can remain sealed until an authorized action requires them. Supakeep brokers them directly to the destination instead of dropping them into an agent prompt.

One boundary, wherever AI runs

Security posture

Research alpha, explicit boundaries.

Supakeep is not currently a certified security product. It cannot control traffic that bypasses its enforcement boundary.

The architecture treats models, prompts, tool metadata, remote MCP servers, and downstream services as potentially buggy or adversarial. The product goal is to move trust decisions outside the model itself.
