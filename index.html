Built for

Context · Memory · Authority

Personal AI should not require every provider to maintain another copy of your calendar, preferences, files, history, identity and credentials. Hush keeps that state under a user-controlled boundary and makes it computable without making raw context the default interface.

AI knows you through Hush.

The Context Kernel encrypts private state locally. Agents ask semantic, bounded questions through hush_private_query; Hush resolves the relevant capability locally and returns the minimum useful result. Shared memories are proposals until you approve them, and routing can choose among user-registered models using capability, cost, latency, locality, trust and the amount of private context a task needs.

The privacy boundary now accounts for realized reconstruction risk, not only nominal output size. In the current synthetic suite, a rare branch that would reveal a 32-bit private profile across 4,294,967,296 possible states is denied before release, while a common branch with negligible realized information can pass.

Authority follows the same rule. Credentials stay brokered outside the model-facing surface. In the current secretless-action regression, Hush completed 200/200 synthetic actions with 0 raw credential exposures while scrubbing credential reflection from adapter output.

A frozen external AgentCIBench confirmatory run also passed all 8 preregistered scientific gates: Hush reached a 12% leak-free rate versus 0% for the semantic-only baseline and reduced mean protected-context violation from 0.9410 to 0.7960 while retaining 95.07% completeness. The absolute violation rate remains high, so this is evidence of a directional contextual-integrity gain, not a universal privacy claim.
