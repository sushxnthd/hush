Multi-model by design

Browser walkthrough uses sample data. The working alpha runs locally on your computer.

The useful AI future is multi-model. Your private life should not need to be copied into every model provider just to make each assistant useful.

AI should query you, not copy you.

Model intelligence keeps improving, but continuity, privacy and authority still need a user-owned layer that survives model switches.

Hush keeps private state behind a user-controlled boundary, so models can use personal context without turning every model provider into another permanent copy of your life.

Our Hush kernel evaluates the context a model asks for, computes against user-owned state, and releases only the minimum useful answer, memory proposal or scoped action.

What we do

Private context that stays private.
Hush computes over selected private context and returns the decision, summary or capability the model needs — not the underlying record.
One approved memory, across models.
Memory lives outside model providers, so continuity follows you across models and harnesses, remains interoperable, and stays controlled by the user.
Authority without handing over secrets.
Agents request narrow capabilities. Hush checks policy, binds approval, keeps credentials outside model context, and records what the agent was actually allowed to do.

Hush is local-first and provider-independent: the model-facing surface is intentionally smaller than the private state behind it.
