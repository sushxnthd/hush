The useful AI future is multi-model. Your private life should not be duplicated into every model provider just to make each assistant useful.

AI should query you, not copy you.

Hush keeps private state behind a user-controlled boundary. An AI asks a bounded question, Hush computes against the relevant local or encrypted context, and only the approved result crosses the boundary. Memory can travel across providers without becoming provider-owned. Actions use scoped authority instead of model-visible credentials.

What we do

001YOU

Private context that stays private.

Models get the decision, summary or capability they need — not the raw records, secret fields, file paths or unrelated context behind it.

002

One approved memory across models.

Assistants can propose what should be remembered. Hush keeps a canonical user-owned memory layer so continuity follows you instead of staying trapped inside one provider.

003KEYOK

Authority without handing over secrets.

Agents request narrow capabilities. Hush checks policy, binds approval, keeps credentials outside model context and records what actually happened.

Hush runs where your context lives.

The privacy boundary should not depend on one model vendor. Hush is designed as a user-owned layer that can sit beside the browser, desktop, local services and model harnesses.

001

002
On your desktop

003
Inside your AI harness
MCP, plugins and APIs expose narrow capabilities instead of raw credentials and raw personal data.

Privacy is the product boundary.

Hush is built around local/private computation, explicit consent, bounded disclosure, secretless agent actions and auditable receipts. The current alpha is research software, not a certification claim.
