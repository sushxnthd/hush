Hush keeps personal context under your control, answers bounded questions locally, carries approved memory across models, routes work under privacy constraints, and brokers actions without handing agents your credentials.

Personal AI should not require every provider to maintain another standing copy of your calendar, files, messages, preferences, identity and credentials.

AI should query you, not copy you.

Hush keeps private state behind a user-controlled boundary. An agent asks a semantic question through hush_private_query; Hush resolves the relevant capability locally and returns the minimum useful result. Shared memories remain proposals until the user approves them. Actions use scoped authority and secret references instead of model-visible credentials.

What Hush does

001YOU

Private context that stays private.

Hush computes over selected private fields locally and returns the bounded decision the model needs, not the underlying record, path or extraneous values.

002

One memory, across models.

Any AI can propose a preference or fact, but only the user can approve it into Hush's canonical shared memory. Continuity moves with the user instead of staying trapped in one provider.

003KEYOK

Authority without handing over secrets.

Agents request narrow capabilities. Hush checks policy, binds exact approvals, keeps credentials outside model context and records receipts for what actually happened.
