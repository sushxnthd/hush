The path to genuinely personal AI is not to copy more of a person into every model. It is to let any model compute with private context while that context stays under the user’s control.

Personalization should not require possession.

Today, the normal interface is retrieval: an agent asks for your calendar, budget, identity, history, preferences or credentials and those values are placed into model context. Every provider becomes another copy of you.

Supakeep flips the interface. Agents bring candidate decisions to a local trust boundary. Private Decision Programs evaluate those candidates against user state locally, and only a deliberately bounded result leaves the boundary.

When an exact value is finally required for an authorized action, Supakeep can broker that value to the destination rather than revealing it to the model.

What we do

Private context that stays private.
Agents can request predicates, buckets and candidate selection without receiving the private attributes that powered the decision.
One trajectory across every agent.
Privacy accounting follows the task, so changing agents, sub-agents, sinks or natural-language purpose does not silently reset cumulative exposure.
Authority outside the model.
Scoped Grants, exact-action approvals, credential brokerage and tamper-evident receipts make the model a requester of authority rather than the authority boundary itself.

The current implementation is an alpha/reference implementation. Production key storage, hardened connectors and broader side-channel defenses remain active work.

Research

Supakeep is an experiment in a provider-neutral trust layer for personal AI. The immediate falsification target is whether blind personalization can preserve most raw-context task utility while exposing dramatically less exact private information to the model.
