Private Mode for every AI.

Hush is the user-owned trust layer between you and AI systems. It keeps private context under your control, answers bounded questions locally, carries approved memory across models, and brokers actions without handing agents your credentials.

AI systems are increasingly useful because they know more about the person using them. The default way to get there is also the dangerous one: every provider keeps another copy of your files, preferences, history, identity, calendar, messages and credentials.

Hush separates personalization from model ownership. Your private state lives behind a user-controlled boundary. An agent asks a semantic question through hush_private_query, and Hush computes the minimum useful answer locally instead of exposing the underlying record.

Memory works the same way. Models may propose shared memories, but only the user can approve them into the canonical store. Actions use scoped authority, secret references and receipts so an agent can do useful work without receiving a reusable credential.

What Hush does

001YOU

Private context that stays private.

Hush resolves bounded questions locally over encrypted context and selected connector fields. Models receive the decision they need, not the record they do not.

002

One memory, across models.

Any AI can propose a preference or fact through Hush, but the value does not become canonical shared memory until the user approves it.

003KEYOK

Authority without handing over secrets.

Agents request narrow capabilities. Hush checks policy, binds exact approvals, brokers credentials outside model context and records tamper-evident receipts.
