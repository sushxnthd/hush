# Hush

Private mode for every AI.

Hush is a user-owned trust layer for private context, cross-AI memory, and scoped authority across models.

## Mission

AI should query you, not copy you. Hush keeps private context behind a user-controlled boundary and returns bounded results instead of wholesale personal data.

## What Hush does

- Private computation over sealed or local context.
- One approval-gated, provider-neutral memory across supported AI systems.
- Scoped Grants and secretless actions so agents can act without receiving long-lived credentials.
- Cumulative reconstruction accounting across tasks, agents, sinks, purposes, trajectories, and profile revisions.

## Research evidence

- Scientific Superiority v1: 4,000 paired synthetic personalization tasks; 100% Hush oracle agreement; 0.000 exact private input attributes per Hush task.
- Frozen AgentCIBench: 8/8 preregistered scientific gates passed; 95.07% completeness; 15.4% relative reduction in exact protected-context violation versus matched semantic-only retrieval; paired leak-free wins 6–0, p = 0.03125.
- AgentLeak: 0% credential-canary leakage with 100% task success across 50 paired production-ActionBroker traces.
- Lineage-aware v1f: 97.01% completeness on the development pool; development-only, not confirmatory.

These results are research evidence, not a security certification or independent reproduction.
