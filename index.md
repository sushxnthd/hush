# Hush

Your context. Your call.

Hush is a user-owned context and permission layer for AI.

## Use today
- Browser workspace: https://sushxnthd.github.io/hush/app/ — encrypted notes, approved memory, manual reviewed AI context, encrypted backups.
- Setup: https://sushxnthd.github.io/hush/start/ — local runtime and MCP connection guidance.

## Scope
The browser workspace is not an AI proxy or the native computation kernel. It makes no model calls. The local runtime is a release candidate with external registration, signed distribution and independent assurance gates pending.
