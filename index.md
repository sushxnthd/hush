# Hush

Your AI should know you. You should stay in control.

Hush is an engineering alpha for user-owned private context, approved cross-AI memory and permissioned actions.

- [Try the sample-data walkthrough](https://sushxnthd.github.io/hush/demo/)
- [Set up the local alpha](https://sushxnthd.github.io/hush/start/)
- [Product](https://sushxnthd.github.io/hush/product/)
- [Research](https://sushxnthd.github.io/hush/writing/)
- [Security](https://sushxnthd.github.io/hush/security/)
- [Support](https://sushxnthd.github.io/hush/support/)

The browser walkthrough does not connect a model or run the encrypted runtime. The working alpha requires Node.js 22+, Git and local setup. Hosted accounts and one-click onboarding are not available yet.
