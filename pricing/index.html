Questions

Is there a paid Hush plan?
No paid plan or hosted account is offered on this website.
Do I need an AI API key?
The browser workspace makes no model calls. You prepare reviewed context and paste it into your chosen AI. Local workflows may have separate provider requirements.
Does this include cloud sync?
No. Browser storage is tied to the device and browser. Keep encrypted backups.
Can I use the runtime in production?
The runtime is a release candidate. Review security scope, setup requirements and the remaining release gates before relying on it.
