v0.9 alpha

Changelog.

What changed, and what the change actually proves.

October 5, 2026

18
Independent AgentLeak regression passed.
Across 50 paired production ActionBroker traces, Hush preserved 100% task success with 0% credential-canary leakage, 0% any-finding rate and mean risk 0.0. The naive path leaked the synthetic credential canary in 100% of trials.
17
Bounded computation reached structured connector fields.
160/160 controlled decisions across Gmail, Calendar, Drive and GitHub were correct, with zero exact benchmark-secret exposures and zero connector-path exposures.
16
Lineage-aware context representation became freeze-ready.
On 67 development scenarios, completeness stayed at 0.9701 while protected-context violation fell to 0.7712; paired leak-free outcomes were 7–0. A fresh untouched evaluation is still required before a new confirmatory claim.
15
v1.2 acceptance contract made canonical.
The next release is defined by explicit product, privacy, authority, integration and validation gates rather than a loose feature list.

Earlier

14
Secretless actions preserved task success.
A 200-trial synthetic action regression completed every Hush action with zero raw credential exposure on the model-facing surface.
13
External AgentCIBench confirmatory result passed.
Hush passed all eight frozen preregistered gates, reached 95.07% completeness and produced six Hush-only leak-free outcomes versus zero for the semantic-only baseline.
12
Approval-gated cross-AI memory shipped.
Any AI can propose a fact or preference, but only the user can approve it into canonical Hush memory.
11
Privacy-aware model routing shipped.
Tasks can be routed across user-registered models using capability, cost, latency, locality, trust and private-context mode.
