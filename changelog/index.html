A clearer path from idea to use.

Product changes and current availability, without hiding unfinished release gates.

8 OCTOBER 2026

Your boundary, made visible.

  • An interactive Keep, Approve, Review and Share diagram explains the browser workflow.
  • Motion can be paused; offscreen media and background animations stop.
  • A refined Hush website with a reading-progress marker, animated controls and a direct path into the workspace.
  • Packaged Linux, macOS and Windows keystore verification now passes, including a fix for cold PowerShell startup detection.
8 OCTOBER 2026

Notes that can grow with you.

  • Edit existing private notes without making duplicate records.
  • Cancel edits or review before replacing an unsaved draft.
  • Approved memories retain their original text when a note changes.
  • Backup export detects changes made in another tab.
7 OCTOBER 2026

Browser workspace · early access

  • Encrypted browser workspace with private notes and text / Markdown import.
  • Memory proposal, explicit approval, rejection and forgetting.
  • Selected context preparation with exact preview and approved clipboard copy.
  • Credential-pattern redaction, encrypted backups, restore and idle lock.
  • New product, research, investor overview and support surfaces.
