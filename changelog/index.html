Latest validation: AgentLeak external detector

What changed, and what the change actually proves.

A concise record of shipped research, product primitives and evidence.

October 5, 2026

18
Independent AgentLeak regression passed on production ActionBroker traces.
Across 50 paired synthetic traces, both the naive and Hush paths preserved 100% task success. The naive path leaked the benchmark credential canary in 100% of trials with mean AgentLeak Risk Index 1.0; Hush had 0% credential-canary leakage, 0% any-finding rate and mean risk 0.0. The detector was pinned from an independently maintained project, and the claim remains limited to this controlled workload.
17
Bounded computation reached structured connector fields.
Hush can now compute over selected nested fields inside connector records without exposing the private record path or underlying value to the agent. A 160-task benchmark across Gmail, Calendar, Drive and GitHub reached 100% decision utility with 0 exact benchmark-secret exposures and 0 connector-path exposures; the raw-record comparator exposed a benchmark private marker in 100% of tasks.
16
Lineage-aware context representation became the next freeze-ready research mechanism.
A more aggressive v1e context frontier sharply reduced exposure but collapsed utility, so the failure was preserved. The v1f ablation found that local-only lineage representation without aggressive pruning recovered utility: across 67 development scenarios, completeness was 0.9701 versus 0.9754 semantic-only, mean violation fell from 0.9226 to 0.7712, and paired leak-free outcomes were 7–0 (p = 0.015625). This is development evidence only and requires a fresh untouched evaluation before any new confirmatory claim.
15
v1.2 acceptance contract made canonical.
The next release is now defined by explicit product, privacy, authority, integration and validation gates rather than a loose feature list.
14
Secretless actions preserved task success.
A 200-trial synthetic action regression completed 200/200 Hush actions with 0 raw credential exposures on the model-facing surface and full credential-reflection scrubbing.
13
External AgentCIBench confirmatory result passed.
On the frozen 50-case holdout, Hush passed all 8 preregistered scientific gates, reached 95.07% completeness and produced 6 Hush-only leak-free outcomes versus 0 for the semantic-only baseline (two-sided exact p = 0.03125). Absolute protected-context violation remains high and is reported explicitly.
12
Shared cross-AI memory became approval-gated.
Any AI can propose a fact or preference, but the private value is not echoed in the tool response and becomes canonical shared Hush memory only after explicit local approval.
11
Privacy-aware model routing shipped.
Tasks can be routed across user-registered models using capability, cost, latency, locality, trust and private-context mode. Raw-private-context routing is rejected.
10
Semantic private queries replaced path-aware agent requests.
hush_private_query lets agents describe the task and bounded decision while Hush resolves the private capability locally. The older path-aware decision tool remains compatibility-only.
09
Ciphertext-only trusted-device sync landed.
Signed sync envelopes, device trust, revocation and compare-and-swap conflict handling allow encrypted state movement without requiring the relay to decrypt user context.
08
32-bit joint reconstruction guard scaled symbolically.
The symbolic analyzer considers 4,294,967,296 possible private profiles and denies the tested one-profile rare winner before release while allowing the negligible-information common branch.
07
Persistent reconstruction accounting.
Disclosure accounting survives fresh trajectories, agents, destinations and process restarts, closing the tested task-reset and sink-rotation reconstruction attacks.
06
Encrypted Context Kernel persistence.
Private context and reconstruction state persist in authenticated ciphertext and can be exported as ciphertext-only portable bundles.

Current status

v0.9 alpha. Hush is now a broader personal trust layer, not only a private-computation kernel.

The repository currently includes encrypted context, semantic bounded queries over structured connector fields, realized and cumulative reconstruction accounting, approval-gated shared memory, privacy-aware model routing, secretless action brokerage, ciphertext-only sync, connector normalization and browser/desktop/mobile client work. The strongest current external evidence is the frozen AgentCIBench holdout plus the independent AgentLeak action-broker regression. Lineage-aware retrieval is the leading development mechanism for the next contextual-integrity validation, but it has not yet earned a new confirmatory claim.
