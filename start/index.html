Set up the local alpha.

Install Node.js 22+ and Git, then open your terminal. There are no package dependencies to install.

  1. Download Hush.

    Clone the source and open the project folder.

    git clone https://github.com/sushxnthd/hush.git
cd hush

  2. Choose a local passphrase and start.

    Replace the example with your own long passphrase. It unlocks encrypted private context. Keep it on your computer.

    export HUSH_CONTEXT_PASSPHRASE='replace-with-your-own-long-passphrase'
npm start
    $env:HUSH_CONTEXT_PASSPHRASE = 'replace-with-your-own-long-passphrase'
npm start

    Keep using the same passphrase when you restart. OS keychain integration is still in development.

  3. Open your dashboard.

    Keep the terminal running and open http://127.0.0.1:8787 on the same computer. The dashboard includes trust settings, approvals, a credential vault, a redaction sandbox and receipts.

    The link connects to your own machine. GitHub Pages hosts this website; it does not run your Hush server.

Connect an AI client.

The local alpha exposes experimental MCP tools at http://127.0.0.1:8787/mcp. Use an AI client that supports a local HTTP MCP endpoint and follow that client’s connection instructions.

Opening ChatGPT or Claude does not automatically connect Hush. Hosted clients may not reach your local endpoint. Broad client compatibility and one-click connection flows are still being validated.
