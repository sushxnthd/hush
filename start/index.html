THE SIMPLE START

Use Hush in your browser.

  1. Open the workspace and choose sample mode or create a private workspace with a long passphrase.
  2. Add a private note. Propose and approve a memory you want to reuse.
  3. Open Prepare for AI, write your task and select relevant approved memories.
  4. Review the full text, approve a copy, then paste it into your AI.
  5. Download an encrypted backup in Settings & backup.

Your passphrase never leaves this page. Hush cannot recover it. Browser storage is per device and per browser; it is not automatic cloud sync.

ADVANCED SETUP · NODE.JS 22+

Run Hush on your computer.

Install Node.js 22+ and Git. The runtime has no npm package dependencies.

1. Get the source.

git clone https://github.com/sushxnthd/hush.git
cd hush

2. Start the runtime.

npm start

Keys use Windows DPAPI, macOS Keychain or Linux Secret Service where available. Linux needs a working Secret Service and secret-tool. Production mode refuses a file-key fallback unless explicitly configured. Development mode can use a restricted file key; the dashboard reports the actual backend.

3. Open the dashboard.

Keep the runtime running. In a second terminal from the same folder:

node clients/desktop/hush-desktop.mjs dashboard

The launcher opens an authenticated, same-device dashboard. Production mode requires local client authentication and an OS-backed keystore. This website cannot access your computer’s runtime.
