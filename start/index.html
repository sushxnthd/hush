Use Hush in your browser.

  1. Open the workspace and choose sample mode or create a private workspace with a long passphrase.
  2. Add a private note. Propose and approve a memory you want to reuse.
  3. Open Prepare for AI, write your task and select relevant approved memories.
  4. Review the full text, approve a copy, then paste it into your AI.
  5. Download an encrypted backup in Settings & backup.

Your passphrase never leaves this page. Hush cannot recover it. Browser storage is per device and per browser; it is not automatic cloud sync.

Open the workspace

Run Hush on your computer.

Install Node.js 22+ and Git. The runtime has no npm package dependencies.

1. Get the source.

git clone https://github.com/sushxnthd/hush.git
cd hush

2. Start Hush.

For a combined runtime start and authenticated dashboard launch, run node clients/desktop/hush-open.mjs. Portable candidates include a hush-open launcher and their own Node runtime. For a terminal-managed session:

npm start

Keys use Windows DPAPI, macOS Keychain or Linux Secret Service where available. Linux needs a working Secret Service and secret-tool. Normal startup refuses a file-key fallback unless explicitly configured and requires local authentication. Portable launchers enforce production mode. Only explicit development fixtures should select a restricted file key; the dashboard and doctor report the actual backend.

3. Open the dashboard.

Keep the runtime running. In a second terminal from the same folder:

node clients/desktop/hush-desktop.mjs dashboard

The launcher opens an authenticated, same-device dashboard. Run npm run doctor to inspect authentication, OS keystore and audit integrity. This website cannot access your computer’s runtime.
