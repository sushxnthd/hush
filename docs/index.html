WORKSPACE GUIDE

A useful first five minutes.

Everything you need to get started with the browser workspace.

01 / CAPTURE

Keep notes on your side.

Create a workspace using a unique passphrase of at least 12 characters. Save notes or import text and Markdown files. Use Edit on a saved note to change it, then Save changes. Editing preserves the note and leaves previously approved memories unchanged. Cancel edit keeps the saved note as it was. Notes stay private; they are not automatically included in prepared AI context.

02 / REVIEW

Turn a useful fact into memory.

Use “Propose a memory” from a note or write a short memory directly. Edit it into the smallest useful fact. It remains pending until you approve it. Rejected memories are excluded. Forgetting removes the record from this workspace.

03 / SHARE

Review the exact text.

In Prepare for AI, enter a task and select approved memories. Review the resulting prompt. The detector flags some credentials and email addresses, but it cannot find every private detail. Redact detected patterns or edit the original input. Approve the copy only after reviewing it.

The destination selector labels your local copy event. It does not send a request to that provider. Open the provider separately and paste when you choose. Hush cannot remove a copy already shared with an external service.

04 / RECOVER

Back up before you need it.

Download an encrypted backup from Settings & backup. To restore, select that file and enter its original passphrase. Restoring replaces the workspace in this browser after confirmation. Export the current workspace first.

There is no passphrase reset. Clearing browser data can erase the local workspace. A backup keeps an encrypted snapshot, including records you later remove. Keep the file and passphrase safely.
