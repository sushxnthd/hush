Keep private information private

Do not include passwords, tokens, private notes, backups or personal records in a public issue. Use synthetic data and the smallest reproduction that demonstrates the problem.

Choose a reporting path

The repository’s Security tab lists the reporting options currently available. If private reporting is available, use it for sensitive vulnerability details. Hush has not published a guaranteed response time or a paid bounty program.

Open repository security↗

What helps us investigate

  • The affected surface and commit or website route.
  • Reproduction steps using synthetic records.
  • The expected boundary and the observed result.
  • A minimal log or screenshot with sensitive information removed.

Test your own workspace

Use a disposable workspace or local test environment you control. Do not access another person’s data, interrupt services or test connected provider actions without authorization.
