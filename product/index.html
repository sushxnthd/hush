Private context

01
Ask for the decision, not the database.
Private Decision Programs run predicates, ranking, filtering, counting and selection against encrypted or local state and return a bounded result instead of the raw record.
02
Connector-backed computation.
Gmail, Calendar, Drive and GitHub records can participate in bounded decisions while exact benchmark secrets and connector paths remain outside the model-facing output.
03
Disclosure is cumulative.
The reconstruction firewall accounts across tasks, agents, sinks, purposes, trajectories and profile revisions so a sequence of individually small answers cannot silently become unrestricted reconstruction.

Cross-AI memory

Models may propose facts and preferences, but canonical memory remains user-owned, approval-gated and provider-neutral. The private value is not automatically echoed back to the proposing model, and the same approved state can travel across supported providers.

The v1.2 goal is not “another memory store.” It is a shared personal trust layer: memory, private computation and authority are governed by the same user-controlled policy and receipt system.

Scoped authority

A
Signed Grants.
Authority is explicit and narrow: agent, sink, purpose, category, resource, action and expiry can be bound into a scoped grant instead of becoming ambient permission.
B
Secretless actions.
The ActionBroker resolves long-lived credentials behind the Hush boundary and exposes the action result, not the credential, to the model-facing path.
C
Receipts, revocation and fail-closed policy.
Exact approvals bind to the action that executes. Unknown tools, stale writes, revoked grants and policy violations can fail closed while tamper-evident receipts preserve an inspectable trail.
