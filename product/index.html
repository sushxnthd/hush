What a memory is

Notes are what you keep privately. Memories are what you choose to reuse.

Private notesApproved memories
WhatThe text you write or importA fact or preference you approve
ExamplesA journal entry, a project note, Markdown“I prefer quieter places.”
RoleYour private source materialSelectable context for an AI task
LifecycleYou add, edit and removeYou propose, approve, reject or forget

Saving a note does not automatically make it shared memory. Editing a note does not silently change an already approved memory. Every proposal has its own review.

Keep, approve, review, share

A useful starting point for personal AI, with a deliberate choice at each boundary.

Keep. Write it privately.
Create a private note or import text and Markdown. Your saved browser workspace is encrypted using your passphrase.
Approve. Remember deliberately.
Propose a reusable fact or preference. Approve or reject it in the memory queue. Forget a memory when you no longer want it reused.
Review. See exactly what leaves.
Write a task and select relevant approved memories. Inspect the complete prepared prompt before choosing to share it.
Share. Make the final call.
Approve a copy to your clipboard, then paste it into your AI. Hush does not automatically send the browser prompt to a provider.

The browser workspace does not intercept AI traffic or enforce permissions in another application. Text you paste into an AI is then subject to that provider’s terms and privacy policy.

Workspace guide↗

The local Context Kernel

AI should be able to ask a useful question without receiving your entire private profile.

The local runtime computes bounded predicates, buckets and candidate selection against encrypted private state. It accounts for repeated explicit disclosures and separates memory proposals from approval.

Bounded computation
Return a limited task result while keeping the underlying private facts behind the runtime’s boundary. Inspect the research for the tested scope and limitations.
Cross-AI memory
Supported MCP agents can propose memories to the local approval queue. The owner decides what enters shared encrypted context.
Scoped authority
Supported provider actions use secretless brokerage, exact-action approval and signed receipts. Provider registration and configuration are required.
