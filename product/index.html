One private layer between you and every AI.

Hush keeps personal context under user control, computes bounded answers over connector data, carries approved memory across models, routes tasks with privacy constraints, and brokers actions without exposing long-lived credentials.

Private queries

01
Agents describe the decision, not the private path.
hush_private_query resolves the capability locally and returns only the bounded result. Raw paths and unrelated values stay behind the boundary.
02
Connector-backed computation.
Gmail, Calendar, Drive and GitHub records can be filtered, counted, selected and checked without copying the full private record into model context.
03
Disclosure is cumulative.
Hush accounts for what prior answers already revealed so separate tasks and agents cannot simply reconstruct the user one bit at a time.

Shared memory

Models may propose facts or preferences, but the private value is not echoed back and it becomes canonical shared memory only after local user approval. The memory belongs to the user, not the provider.

One approved memory store can serve multiple models without giving any single model unilateral ownership of the user's long-term state.

Scoped authority

A
Secretless actions.
Agents receive narrow action capability rather than reusable credentials. Credential material stays brokered outside the model-facing surface.
B
Exact approvals.
Approval binds to the action that executes rather than becoming broad permission for later side effects.
C
Receipts and fail-closed policy.
Unknown tools, stale writes, reconstructed private outputs and unapproved memory writes can fail closed while the action trail stays inspectable.
