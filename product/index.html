A trust layer between the user and every model.

Hush gives agents private context, shared memory, model routing and scoped authority while keeping raw personal state outside the model-facing surface.

Context Kernel

01
Encrypted, user-owned state.
Private records, preferences, metadata and reconstruction state persist under authenticated encryption. Portable sync envelopes carry ciphertext and opaque identifiers rather than readable personal context.
02
Semantic bounded queries.
hush_private_query lets the agent describe the task and decision it needs. Hush resolves the private capability locally and returns the minimum useful result rather than a path or raw value.
03
Approval-gated shared memory.
Any AI can propose a fact or preference. The value is not echoed in the tool response and becomes canonical Hush memory only after explicit local approval.

Routing and authority

04
Privacy-aware model routing.
hush_route_task can consider capability, cost, latency, locality, trust and the amount of private context a task requires. Requests for raw private context are rejected.
05
Secretless actions.
Scoped grants, exact approvals, secret references and receipts let agents act without receiving long-lived credentials.
06
Ciphertext-only sync.
Trusted-device identities, signed envelopes, revocation and conflict detection provide the current synchronization primitive without requiring a relay to decrypt the user's context.

The model is not the security boundary.

Hush enforces policy outside the model: encrypted local context, bounded computation, cumulative disclosure accounting, approval-gated memory, credential brokerage, exact action approvals and ciphertext-only sync.

Known boundary: current research is strongest on explicit output channels. Timing, compromised hosts, bypass traffic, network metadata, covert channels and unmediated side effects remain outside the guarantee.
