Alpha use notice · updated 7 October 2026

Know what you’re trying.

Hush is experimental software. This page describes the current product’s availability and limits.

Current access.

The website and sample-data walkthrough are free to explore. There are no paid plans, hosted accounts or subscription purchases on this site.

What the walkthrough means.

The browser walkthrough illustrates private decisions, approved memory and permissions. It does not connect a model, protect another application, send a real message or run the encrypted local runtime.

Using the alpha.

The local runtime is an engineering alpha. Features and interfaces may change, and current tests are not a security certification or a guarantee for every real workflow. Evaluate it with sample or non-sensitive data before relying on it.

Your connections.

You control the services and AI clients you configure. Their own terms and privacy policies continue to apply. A Hush setup prompt does not authorize access or establish a service connection.

Source and feedback.

The repository contains the current implementation and documentation. Refer to repository licensing information before redistribution. Use Support to report problems.
