# Hush Product

One user-owned trust layer between you and every AI.

Hush combines encrypted private context, bounded computation, cross-AI memory, scoped Grants, secretless actions, receipts, and revocation behind one user-controlled policy boundary.

## Private context

Private Decision Programs run predicates, ranking, filtering, counting, and selection against local or encrypted state and return the bounded result rather than the underlying record. Connector-backed computation currently covers controlled Gmail, Calendar, Drive, and GitHub workloads.

## Cross-AI memory

Canonical memory is user-owned, approval-gated, and provider-neutral. Models may propose facts or preferences, but the private value is not automatically echoed back and no single model provider owns the user’s long-term state.

## Scoped authority

Signed Grants bind authority to narrow dimensions such as agent, sink, purpose, category, resource, action, and expiry. The ActionBroker resolves long-lived credentials behind the Hush boundary. Exact approvals, revocation, fail-closed policy, and tamper-evident receipts constrain execution.

## Evidence

- Scientific Superiority v1: 4,000 paired synthetic tasks; 100% Hush oracle agreement and 0.000 exact private input attributes per Hush task.
- Frozen AgentCIBench: 8/8 gates passed; 95.07% completeness; 15.4% relative reduction in exact protected-context violation vs matched semantic-only retrieval.
- AgentLeak: 0% credential-canary leakage with 100% task success across 50 paired traces.
- Adaptive reconstruction evaluation: 0% exact recovery under tested Hush conditions versus 100% for the unprotected control.

The evidence classes are deliberately distinct and are not a security certification or independent reproduction.
