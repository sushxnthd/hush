The path to useful personal AI is to make context available without making raw private state portable. Hush turns into the default interface between a person and a model.

Private state stays behind a user-controlled boundary. Agents ask semantic questions, Hush computes locally over the relevant capability, and the model receives the minimum useful result. Approved memories can move across models. Scoped actions can run without exposing credentials. A follows disclosure across tasks and agents.

The system is being falsified against external and controlled evaluations rather than sold as “perfect privacy.” The current and define the strongest claims Hush can make today.
