Introducing HushRead the thesis ↗

Hush is building private mode for every AI.

One user-owned layer for private context, shared memory and permissioned actions across models.

Build with HushExplore the system

Works with

The useful AI future is multi-model. Your private life should not need to be copied into every model provider just to make each assistant useful.

AI should query you, not copy you.

Model intelligence keeps improving, but continuity, privacy and authority still need a user-owned layer that survives model switches.

Hush keeps private state behind a user-controlled boundary. An AI asks a bounded question; Hush computes against the relevant context and returns the minimum useful answer.

The model-facing surface is deliberately small: bounded queries, approved memory proposals and scoped capability requests. The private state behind that surface can remain much larger.
