Help & FAQ

Let’s get you unstuck.

Answers for your first Hush session and a direct route to the project’s issue tracker.

Can I use Hush without installing anything?

Yes. Try the browser walkthrough with sample data. The working alpha runs locally and needs Node.js 22+ and Git.

Does this website have a hosted Hush account?

No. This site explains the product and hosts the walkthrough. Hosted accounts, paid plans and one-click onboarding are not available yet.

Why doesn’t the dashboard link open?

The dashboard is served by Hush on your computer. Run npm start in the project folder, keep the terminal open, and then visit http://127.0.0.1:8787. Check the terminal for an error or a port conflict.

What if encrypted context is unavailable?

Set HUSH_CONTEXT_PASSPHRASE before starting the server. Restart with the same passphrase you originally chose. A different passphrase will not unlock existing encrypted context.

Does Hush automatically connect to ChatGPT or Claude?

No. The local alpha has an experimental MCP endpoint, and compatible clients need manual configuration. A setup prompt provides instructions; it does not install or authorize a connection.

Where does my data go?

The walkthrough uses sample data in page memory. Local-alpha data lives in your project’s data/ directory. Connector, sync and model workflows depend on what you explicitly configure. Read the privacy notice and security boundary.

Can I use this as production security software?

Hush is an engineering alpha. The current evaluations do not establish general security or third-party certification. Read the threat model before relying on it for sensitive workflows.

Report a bug or ask a question.

Open a GitHub issue with the page or feature, what you expected, what happened, your browser or Node version, and steps to reproduce.

Open an issue

GitHub requires its own account. Keep credentials and private records out of public issues. For security reports, use the project security policy.
